## 新功能與改進

🪟 支援 Windows：可從 GitHub Release 下載，或以 Scoop 安裝。感謝 @MaoliWolf（#1）。

🏠 「今天」分頁更名為「首頁」。

📚 課程頁捲動後，課程名稱會顯示在頂端列。

🖥️ macOS：頁面標題移到視窗按鈕那一列，側邊欄圖示與視窗按鈕對齊。

## 錯誤修正

🔄 下拉重新整理時，課程清單會重新讀取，加退選後的課程會顯示出來。

🔔 登出後不再收到原帳號的提醒；關閉提醒不需要網路；裝置不在台灣時區時，上課提醒時間也正確。

📅 App 跨過午夜仍開著時，行事曆與課表會換到新的一天。

🗓️ 寬螢幕的課表不再把已下課的課程顯示為「上課中」；切換學期時會清除另一學期選取的課程。

🎟️ 在「我的活動」報名或取消後，清單會立即更新。

🧩 公告含錯誤字元、節次格式異常或暫存檔損毀時，不再讓整個清單無法顯示。

🤖 Android：桌面上的名稱改為「TAT CCU」；小工具遇到舊版資料時改顯示空白狀態，不再當機。
